# 指数・対数フィード

指数関数・対数関数の問題を、縦にスクロールしながら1問ずつ解いていくアプリ。

**https://ahaaaaa34.github.io/jhvjh/**

## 使い方

- **上下にスワイプ** … 次の問題へ。答えずに送ったぶんは記録に残らない
- **まん中の書くボタン** … 画面はそのまま、その上に計算を書ける。書いたものはカードに残る
- **解答・解説** … 押すと不正解として記録して、答えと解説を出す
- **右の💬** … 自分で答えを入力して採点する
- **いちばん上のタブ** … 範囲えらび（累乗根・指数の拡張・章末の問題 など）

## 中身

| ファイル | 中身 |
|---|---|
| `index.html` | 画面と、判定・記録・計算スペースのしくみ |
| `data.js` | 問題データ（28範囲・328問） |
| `sw.js` | 圏外でも開けるようにする Service Worker |
| `manifest.webmanifest` | ホーム画面に入れたときの名前とアイコン |

問題データは本編アプリ [ahaaaaa34/tiri](https://github.com/ahaaaaa34/tiri) から写したもの。
